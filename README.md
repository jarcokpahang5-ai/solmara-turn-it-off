One funny line a hopeless tech support agent says to a desperate customer —
an entry for the [make.fun bounty "Have You Tried Turning It Off?"](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) ($10).

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout.
Pure Python 3 standard library, deterministic, no network.

## The line

> Have you tried turning it off and on again? Please say yes — my whole training was that one sentence, and I slept through the refresher.
